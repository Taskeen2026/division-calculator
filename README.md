# Division Calculator with Tkinter

## About the Project

The Division Calculator is a simple, interactive, and user-friendly desktop application developed using Python and the Tkinter library. This application allows users to divide two numbers quickly and accurately through a graphical user interface (GUI).

The project features a clean and attractive interface with a dark blue background, white text, and orange buttons. Users can enter two numbers in separate input fields and click the DIVIDE button to calculate the result instantly.

It also includes input validation and error handling to make the application more reliable and user-friendly. If a user enters invalid data or tries to divide a number by zero, the application displays an appropriate error message instead of crashing.

## Features

- **Simple GUI:** Clean and attractive graphical interface.
- **Division Operation:** Divides the first number by the second number.
- **Decimal Results:** Displays accurate decimal results up to six decimal places.
- **Smart Number Formatting:** Removes unnecessary zeros from decimal results.
- **Zero Division Handling:** Displays an error message when dividing by zero.
- **Input Validation:** Handles invalid or empty number inputs.
- **Clear Button:** Clears both input fields and resets the result.
- **Instant Results:** Displays the calculation directly in the application.
- **User-Friendly Design:** Easy-to-use buttons and input fields.

The application uses a dark blue background with white headings and orange buttons to create a simple and attractive calculator interface.

## How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the Python file.
5. Run the following command in the terminal:

```bash
python division_calculator.py
```

6. Enter the first number.
7. Enter the second number.
8. Click the **DIVIDE** button to see the result.
9. Click the **CLEAR** button to reset the calculator.

## Error Handling

This application includes basic error handling to improve its reliability:

- Prevents division by zero.
- Displays an error message for invalid inputs.
- Handles empty input fields.
- Prevents the program from crashing due to incorrect number entries.
